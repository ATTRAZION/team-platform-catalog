# Каталог модулей Team Platform

Публичный подписанный каталог официальных модулей Team Platform.

- `catalog.json` — манифесты модулей, размеры и `sha512`;
- `catalog.json.sig` — отсоединённая подпись Ed25519 над байтами `catalog.json`;
- `<id>-<version>.mjs` — собранные ESM-модули, на которые ссылается каталог.

Приложение проверяет подпись каталога встроенным публичным ключом, а каждый
модуль — по размеру и `sha512` из каталога. Приватный ключ подписи в репозитории
не хранится.

Адрес каталога:
<https://attrazion.github.io/team-platform-catalog/catalog.json>

Обновление: пересоберите модули и каталог, подпишите его тем же приватным
ключом и замените файлы в этом репозитории. Версии модулей в именах файлов
неизменяемы; старая версия может оставаться рядом с новой.
